# MUBA-HACKATHON-2026-verigonka-truth-engine
VeriGonka is a decentralized AI fact-checker built on the Gonka Network (gonkarouter.io) for MUBA Hacks 2026. It cross-verifies news URLs and text via multi-model consensus, outputting a 0–100% Truth Score, reasoning trace, and auditable Gonka Request IDs to eliminate centralized bias
